# 数学の本の執筆ルール

指定された本に沿う場合、主題を複数の資料から組み立てる場合、講義形式にする場合に共通して使う。
本の計画から、想定読者、既知として扱う定義・結果、証明や計算の詳しさを確認する。
語尾・句読点・用語の表記などは、その本に指定された約束があれば従う。
説明と証明の詳しさは [mathematical-exposition](../../mathematical-exposition/SKILL.md) も参照する。

## 本文を書く

1. **章の入口で問いと到達点を示す。** どんな対象を調べ、章の終わりに何を示せるようになるかを書く。
   準備が長く続くときは、後でどこに使うかを一つ示す。既習事項は、その場で使う形に絞って思い出せるようにする。
2. **定義では対象・条件・名前を明らかにする。** 何を固定し、何を動かすかを先に示す。条件が複数あれば、
   対応が分かるように並べる。記号の約束、境界例、混同しやすい点は、必要なものを定義の近くに置く。
   **各項目の最初の一文で、そこで何を考えるかを示す。** 定義・命題・例・演習を読み始めた時点で、
   主要な記号が何を表すか分かるようにする。たとえば「$X,Y$ を集合とし、$f:X\to Y$ を写像とする。」
   共通の記号もその項目の主役なら種類と所属先を言い添える。証明が途中で導入する補助記号は、導入時に説明する。
   冒頭で対象と結論を一文にできる場合は、一文にまとめてよい。証明の冒頭では、最初に取る対象や仮定、
   または最初に示すことを明らかにする。
3. **例ごとに確かめることを決める。** 初めの例では定義の条件をどう照合するかを見せる。次の例には、
   対象が変わっても使えることや、仮定を外すと何が崩れるかを示す役割を持たせる。具体的な計算が
   概念の導入を助けるときは、計算から始めてよい。
4. **証明では、推論が進む理由を書く。** 短い証明は仮定や対象を取るところから始められる。長い証明では、
   必要に応じて何を示せば十分かを先に示す。対象の取り方、仮定の効く箇所、結論への移り方を言葉で補い、
   式だけで追える計算は式に任せる。「明らか」「同様」で省ける範囲は、想定読者に任せた計算の水準で決める。
5. **つなぎでは、前の結果の使い道か、次に残る問いを書く。** 資料をまたぐときは、仮定・記号・問いの違いが
   読み進めるうえで関係する箇所に説明を置く。順序だけで関係が伝わるところは、そのまま進む。
6. **数学の対象とその扱いが見える日本語にする。** 何を取り、何を仮定し、何が言えたかを追えるように書く。
   「この結果」の指す先が曖昧なら、結果の名前か式を示す。「重要」と言う箇所では、その条件や結果が
   どこで効くかを示す。カードの作業用の見出しやメモは、読者向け本文の言い回しに持ち込まない。

## 文体の参照資料

ワークスペースに指定された場合は、`local/original/book-writing-ja/README.md`
にある対象範囲を参照する。定義・証明・章の導入は、それぞれ同じ役割の箇所と比べる。

## カードに置いて読み返す

- 共有する本文カードに、事実を正しく理解して使うための説明を置く。章の導入、動機、問い、振り返りは、
  その本の読書順に即したつなぎに置く。つなぎに新しい数学的事実が要るときは、該当する本文カードを使うか追加する。
- 執筆中は、新規・変更カードと隣接箇所を短く読む。節がまとまったら読書順に通し、定義が必要な箇所に先行し、
  証明の理由と節の移り方が伝わるかを確認する。自読は既存の執筆工程に含める。
- 独立レビューは [既存の区切り](intake-review.md#when-to-call-an-independent-reviewer) で行う。
  仮定・結論・論証を変えた場合は、変更した数学とその影響先を再確認する。
